This section specifies the JSON representation and evidence-aware prompt templates used to enforce citation insertion, schema conformance, provenance recording, and assembly into LaTeX; we summarize required fields and prompt fragments rather than reproducing the full machine-readable schema.  
Core field groups include \texttt{section\_identity}, \texttt{content}, \texttt{assertions}, \texttt{citations}, \texttt{evidence\_snippets}, \texttt{generation\_metadata}, \texttt{validation}, and optional \texttt{latex\_fragment}; each records types, citation bindings, and provenance for automated checks.  
Post-generation validation checkpoints require schema conformance, per-assertion citations and citation-to-bib consistency, evidence provenance, and assembly safety, with failures recorded in \texttt{validation.validation\_issues} for human review.  
Prompts inject ranked evidence, state the JSON output contract, mandate assertion-level citations and a self-check, and adopt conservative defaults (quote snippets, omit unsupported claims or mark them speculative) to reduce unsupported assertions.
